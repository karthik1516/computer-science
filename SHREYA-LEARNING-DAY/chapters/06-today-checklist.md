---

# If you get stuck

- **Cursor:** Select the confusing part and ask: “Explain this” or “Why might this error happen?”
- **Python error:** Copy the error message and ask Cursor: “I get this error when running the script: [paste].”
- **Data:** Start with the sample CSV in `data/`; only then try downloading from data.gov or CDC.

---

# After today

- You don’t have to code every day. When you hit a policy or law class that uses data or “evidence-based” work, you’ll have a mental model: get data → clean/organize → summarize or graph → interpret. Same idea in Sheets or Python.

- You can come back to this repo anytime: add a new script, try a new dataset, or ask Cursor to help you extend the analysis.

- John Glenn and law school will have courses on research methods, statistics, and sometimes “data for policy.” Today is a friendly head start.

Good luck, and have fun exploring.
