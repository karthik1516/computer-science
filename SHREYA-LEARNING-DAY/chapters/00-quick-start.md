# Quick start (with Dad)

Do this once together so you have the repo on your laptop and open in Cursor.

---

## 1. Fork this repo

On GitHub: open the repo (the one Dad showed you), click **Fork**, and create the fork under **your** GitHub account.

---

## 2. Clone your fork on your laptop

- Install [Git for Windows](https://git-scm.com/download/win) if you don’t have it.
- In a folder you like (e.g. `Documents`), open terminal or PowerShell and run (use **your** GitHub username):

```bash
git clone https://github.com/YOUR_USERNAME/computer-science.git
cd computer-science
```

---

## 3. Open in Cursor

- Install [Cursor](https://cursor.com) and sign in with a free account.
- **File → Open Folder** → choose the `computer-science` folder you just cloned.

You’re in. The rest of the guide is for you to do on your own.
