# Using Cursor to do it easily

**Cursor** is an editor that understands your project and can help you write and change code in plain English.

---

## What you can do

- **Ask Cursor:** Select a line or a file and ask things like:  
  “What does this line do?”  
  “Add a comment that explains this for a policy memo.”  
  “Change this to plot two variables instead of one.”

- **Edit with AI:** Select code or text, then ask for a change. Cursor will suggest an edit; you accept or tweak.

- **Run in the terminal:** As you did in the hands-on chapter, use the built-in terminal to run `python scripts/plot_public_data.py` and re-run after changes.

- **No need to memorize syntax:** You can say “write a Python script that reads this CSV and makes a bar chart by state” and refine from there.

---

## Pro tip

The more specific your prompt (“plot the second column as a bar chart and add a title”), the better the result.
